# Typography

Two families, one job each.

**Bricolage Grotesque** carries the interface — labels, headings, body copy. It has
enough personality to be recognizable without stealing attention from data.

**Spline Sans Mono** carries every number. Applied through the `numeric-data` utility
(`font-variant-numeric: tabular-nums`), so digits share a fixed width and columns of
metrics align vertically.
